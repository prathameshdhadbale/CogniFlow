## 🚀 Quick Start (Frontend)

```bash
# 1. Navigate to project
cd cogniflow-complete

# 2. Install dependencies
npm install

# 3. Setup environment
cp .env.example .env
# Edit .env: REACT_APP_API_URL=http://localhost:5000/api

# 4. Start app
npm start

# Opens at http://localhost:3000
```
